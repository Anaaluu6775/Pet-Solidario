🐾 Pet solidário

Site para cadastrar e consultar entidades de proteção animal (abrigos, adoção, resgate e proteção).

Projeto de estudo feito com HTML, CSS e JavaScript puro.

Funcionalidades
Cadastro de entidades com nome, campo de atuação e pontos de coleta
Lista de entidades cadastradas, com filtro por campo e janela de detalhes
Cadastro de novos campos de atuação
Exclusão de entidades
Layout responsivo (funciona no celular)
Como usar
Baixe ou clone o repositório.
Abra o index.html no navegador (ou use a extensão Live Server do VS Code).
Tecnologias
HTML5
CSS3 (Grid, Flexbox e variáveis CSS)
JavaScript (DOM e localStorage)
Font Awesome (ícones)
Observação

Os dados ficam salvos no localStorage do navegador. Por isso, cada pessoa vê apenas o que cadastrou no próprio navegador.
